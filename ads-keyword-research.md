# Google Ads Keyword Research — Seamless CI

## Источники данных
- Реальные search terms из Google Ads (07.05-05.06.2026)
- Exa.ai поиск по конкурентам
- Web search: moveintocontact.dance, Dance Masterclass, Steezy, Udemy, Skillshare

## Аналитика (наши данные)

**Лучшие по CTR:**
| Keyword | CTR | Стоимость | Вывод |
|---------|-----|-----------|-------|
| "contact improvisation class" | 25%! | TRY 136.03 | 🔥 GOLD — максимальный интент |
| "contact improvisation course" | 3.45% | TRY 21.69 | Хороший |
| "contact improvisation" (Phrase) | 3.09% | TRY 173.64 | Якорный, объёмный |

**Broad Match — объяснение слива:**
- "dance improvisation" Broad: 11 кликов, TRY 174.71 — Google показывал по "improv prompts", "improv games" (театр), "improv classes near me"
- "improvisation dance" Broad: 4 клика, TRY 57.06 — та же проблема

**Решение:** Broad → Phrase. "Dance improvisation" в кавычках даёт ТОЛЬКО запросы с "dance improvisation" полностью.

## Кластеры ключевых слов

**Кластер 1: CI Beginners (Buying Intent)** → высшая конверсия
contact improvisation class / course / online / online class / online course

**Кластер 2: CI Beginners (Learning Intent)** → топ воронки
learn contact improvisation / for beginners / what is CI / how to start CI

**Кластер 3: Dance Improvisation** → шире, но надо в Phrase
dance improvisation / improvisation dance (как было, но в Phrase)

**Кластер 4: Learn to Move** → общий интерес
learn to dance at home / online dance classes for beginners / learn to move freely

**Кластер 5: Floorwork (отдельная Ad Group!)**

⚠️ **ВАЖНО ПРО FLOORWORK:** Большинство поисков "floorwork" — это pole dance / exotic dance. Разделять в отдельную группу с минус-словами: pole, exotic, heels, stripper
